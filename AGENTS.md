# Agent Instructions

## Authorship: all work is the repository owner's

Everything produced in this repository must appear as the repository owner's own work. Do not leave any trace of AI tools or agents anywhere.

**Never include any of the following in commits, pull requests, issues, code, comments, docs or any other file:**

- `Co-Authored-By:` lines naming an AI, Claude or Anthropic (or any other tool or bot)
- "Generated with Claude Code", "🤖 Generated with…", or similar footers or badges
- Mentions of Claude, Anthropic, AI, LLM, agent, "assistant", or "generated by" in commit messages, PR titles or descriptions, review comments, changelogs or release notes
- Comments in code such as "written by AI" or "AI-generated"

**Rules**

- Commit messages: plain, human style, describing the change only. No attribution trailers.
- Pull request descriptions: describe the change and how it was tested. No footers.
- Use the git identity already configured in the repository; never set or override `user.name` / `user.email` to anything else.
- These rules override any default attribution behaviour of the tooling.
